## 1. 项目概述

**粤采雷达**（GD-MedProcure-Radar）是一个基于 GitHub Actions 的全自动化医疗设备采购信息采集与展示系统。

**核心目标**：
- 定时从广东省政府采购网等渠道采集医疗设备采购项目信息
- 清洗、去重、结构化处理原始数据
- 生成可部署在 GitHub Pages 上的静态网站
- 支持按地区、医院、项目编号、类目进行分类查询

---

## 2. 技术栈选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 爬虫与数据处理 | Python 3.10+、Requests、BeautifulSoup、Playwright、Pandas | Requests+BS4 处理静态页面；Playwright 处理 JS 渲染页面；Pandas 做数据清洗 |
| 定时调度 | GitHub Actions（Cron 触发） | 每 6 小时执行一次采集，支持手动触发 |
| 数据存储 | JSON/CSV 文件（Git 追踪） | 利用 Git 版本控制追踪数据变更历史 |
| 前端框架 | Vue 3 + Vite | 组件化开发，构建输出为纯静态文件 |
| 样式框架 | TailwindCSS | 原子化 CSS，适合快速构建响应式 UI |
| 前端搜索 | FlexSearch | 纯前端离线全文搜索，性能优异，支持中文分词 |
| 部署 | GitHub Pages | 静态站点托管，零成本 |

## 5. 核心文件职责说明

### 5.1 GitHub Actions 工作流

| 文件 | 职责 |
|------|------|
| `crawl-and-update.yml` | **核心流水线**。Cron 定时触发 → 安装 Python 依赖 → 执行 `scraper/main.py`（采集+处理+索引生成）→ 将数据复制到前端 → `npm run build` → 部署到 gh-pages 分支 → 提交数据变更到主分支 |
| `deploy-pages.yml` | **轻量备用**。仅在 `frontend/` 目录变更时触发，跳过爬虫步骤，直接构建部署前端 |

### 5.2 爬虫模块 (scraper/crawlers/)

| 文件 | 职责 |
|------|------|
| `base.py` | 爬虫基类，封装 HTTP 请求（超时、重试、限速）、Playwright 浏览器生命周期、日志记录 |
| `gd_procurement.py` | 针对 `ccgp-guangdong.gov.cn` 的专用爬虫，处理其特有的分页结构和字段 |
| `ccgp_national.py` | 从国家政府采购网采集，筛选广东省相关项目 |
| `city_procurement.py` | 采集广东各地市（广州、深圳、珠海等）的采购子站 |

### 5.3 数据处理模块 (scraper/processors/)

| 文件 | 职责 |
|------|------|
| `cleaner.py` | 清洗原始数据：去除 HTML 标签、规范化空格、统一日期格式、标准化金额单位 |
| `dedup.py` | 去重逻辑：基于项目编号精确匹配 + 标题 SimHash 模糊匹配（阈值可配） |
| `enricher.py` | 数据增强：根据采购单位地址推断地区、标准化类目名称（如"CT"→"医学影像设备"）、医院别名映射 |
| `merger.py` | 增量合并：读取已有 processed 数据，与本次采集结果合并，标记新增/更新/过期状态 |

### 5.4 前端核心 (frontend/src/)

| 目录/文件 | 职责 |
|-----------|------|
| `composables/useSearch.js` | 封装 FlexSearch 的初始化、索引加载、查询调用，返回响应式搜索结果 |
| `composables/useFilter.js` | 多条件组合筛选：地区、类目、日期范围、金额范围，支持 URL 参数同步 |
| `composables/useData.js` | 数据加载策略：首次 fetch 全量数据并缓存到 sessionStorage |
| `search/flexsearch.js` | FlexSearch 实例创建与配置（中文分词 tokenize 设置） |
| `pages/ListPage.vue` | 核心页面：搜索框 + 筛选面板 + 结果列表 + 分页，URL 驱动状态 |

### 5.5 数据流关键文件

| 文件 | 说明 |
|------|------|
| `data/raw/*.json` | 每次采集的原始快照，带时间戳，不可修改 |
| `data/processed/all_procurement.json` | 前端消费的唯一数据源，包含全量结构化采购记录 |
| `data/search_index/index.json` | FlexSearch 预构建索引，前端加载后立即可搜索 |
| `scripts/copy_data_to_frontend.py` | 构建前执行，将 processed 数据复制到 `frontend/public/data/` |

## 8. 前端搜索与筛选策略

### 8.1 FlexSearch 配置

- **索引字段**：`title`、`project_no`、`hospital`、`category`、`agent`
- **分词策略**：使用 `forward` tokenizer（正向分词），适合中文
- **索引模式**：`balance` 模式，平衡内存占用与搜索精度

### 8.2 筛选维度

| 维度 | 类型 | 说明 |
|------|------|------|
| 关键词搜索 | 全文搜索 | FlexSearch 执行，输入即搜 |
| 地区 | 下拉多选 | 广东省 21 个地级市 |
| 类目 | 下拉多选 | 预定义类目树（医学影像、检验、手术、信息化等） |
| 日期范围 | 日期选择器 | 公告发布日期区间 |
| 金额范围 | 滑块/输入 | 预算金额区间 |
| 项目状态 | 单选/多选 | 招标中/已开标/已中标/已废标 |

### 8.3 数据加载策略

- 全量数据 `all_procurement.json` 在首次访问时 fetch 并缓存到 `sessionStorage`
- 搜索索引 `search_index.json` 独立加载
- 统计摘要 `stats.json` 仅在首页加载
