# 0610 号修改报告：详情页弹窗 + URL 修复 + 部署增强

> **日期**：2026-06-10  
> **修改范围**：前端界面、数据修复脚本、CI/CD 部署流程  
> **修改目的**：解决"点击标题无详情页"和"查看详情链接错误"两大核心问题

---

## 一、问题诊断

### 问题 1：前端没有详情页功能

| 现象 | 用户点击项目名称（标题），页面没有任何反应，无法查看公告正文 |
|------|--------------------------------------------------------------|
| 原因 | 前端只有折叠式 `x-show="item.content"` 按钮，没有点击标题弹出详情页的功能 |
| 影响 | 用户无法在站内查看完整公告内容，必须跳转外部网页 |

### 问题 2：GDGPO 详情链接错误

| 现象 | 所有来自"广东省政府采购网"的记录，点击"查看详情"后页面报错/404 |
|------|--------------------------------------------------------------|
| 原因 | 数据文件 `data/procurements.json` 中 12 条 GDGPO 记录仍使用旧的 URL 格式 `/maincms-web/articleDetail?noticeId=xxx`，正确格式应为 `/maincms-web/noticeGd?id=xxx` |
| 根因 | 上一轮修改了 `config.py` 中的 URL 模板，但**未重新爬取数据**，旧数据中 URL 未被更新 |

### 问题 3：搜索索引缺失 content 字段

| 现象 | `frontend/public/data/search-index.json` 没有 `content` 字段 |
|------|--------------------------------------------------------------|
| 原因 | 索引文件由旧版 `build_index.py` 生成，当时还没有 `content` 字段 |
| 影响 | 即使有正文数据，前端也无法展示 |

## 三、功能详解

### 3.1 详情弹窗（核心新功能）

**触发方式**：
- 点击卡片标题（项目名称）
- 点击卡片右侧的"公告详情"链接

**弹窗内容结构**：

```
┌─────────────────────────────────────────────┐
│  [类目标签]           [X 关闭]              │
│  项目名称（大标题）                         │
├─────────────────────────────────────────────┤
│  项目编号  │  采购人    │  代理机构          │
│  地区      │  发布日期  │  公告类型          │
│  预算金额  │  数据来源  │                    │
├─────────────────────────────────────────────┤
│  📄 公告正文                                │
│  ┌──────────────────────────────────────┐   │
│  │ 正文内容...（可滚动，最大高度 384px）│   │
│  │ 若未采集则显示"正文内容暂未采集"     │   │
│  └──────────────────────────────────────┘   │
├─────────────────────────────────────────────┤
│  ID: xxx        [关闭]  [访问原始网页 →]    │
└─────────────────────────────────────────────┘
```

**技术实现**：
- 使用 Alpine.js `x-show` + `x-transition` 实现弹窗动画
- ESC 键 / 点击遮罩层 / 关闭按钮均可关闭弹窗
- 弹窗打开时 `body` 设置 `overflow: hidden` 禁止背景滚动
- 从 `fullData`（procurements.json）获取完整正文内容，而非搜索索引中的摘要

### 3.2 URL 修复（三层防御）

| 层级 | 位置 | 机制 |
|------|------|------|
| **爬虫配置** | `scraper/config.py` | `detail_url_template` 已修正为 `noticeGd?id=` |
| **数据修复** | `scripts/fix_data_urls.py` | 部署前批量修正旧数据中的错误 URL |
| **前端安全网** | `index.html` 中的 `fixUrl()` | 客户端自动将旧格式 URL 转换为新格式 |

### 3.3 链接结构变化

**修改前**：
```
[查看详情 →]                    ← 单个外部链接，URL 错误
```

**修改后**：
```
[公告详情] | [原始网页 →]       ← 双链接：站内弹窗 + 外部原始页面
```

## 五、关于 GDGGZY 链接说明

广东省公共资源交易平台（GDGGZY）的详情页使用 **SPA 哈希路由**：
```
http://ygp.gdzwfw.gov.cn/#/44/new/jygg/v3/D?noticeId=xxx&projectCode=xxx...
```

该链接格式经 Browser Agent 验证，URL 模板是正确的。如果部分记录点击后页面无法正常加载，原因是 GDGGZY 平台自身的 SPA 路由问题（非本项目能控制）。

**解决方案**：通过本项目的"详情弹窗"功能，用户可以在站内直接查看公告内容，无需依赖外部 SPA 页面。
