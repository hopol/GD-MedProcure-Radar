## 二、根因分析与修复

### 2.1 问题1：GDGPO 采集失败

**根因**：上一次效率优化将 `connect_timeout` 从 60s 降至 20s，GitHub Actions 海外 Azure 服务器访问国内政府网站 TCP 握手需要 10-30s，20s 不够用。

**状态**：已在 `Docs/11` 中修复为 45s。本次确认：

- 本地 API 测试：**200 OK**，返回 251 条记录 ✅
- `connect_timeout=45` 已在 config.py 中生效 ✅
- `time.sleep(30)` 首页重试等待已恢复 ✅

**验证**：
```
requests.get(GDGPO list_api) → Status: 200, Code: 200, Total: 251, Rows: 5 ✅
requests.get(GDGPO detail_api) → Has desc: True, Desc length: 500 ✅
```

### 2.2 问题2：GDGGZY 链接无法打开

**根因**：广东省公共资源交易平台（ygp.gdzwfw.gov.cn）已强制 HTTPS。当用户浏览器访问 `http://` URL 时，服务器发起 301 重定向到 `https://`，但 **hash fragment（`#/...`）在跨协议重定向中丢失**，导致用户被重定向到网站首页而非详情页。

```
http://ygp.gdzwfw.gov.cn/#/44/new/jygg/v3/D?...  ← 旧链接
      ↓ 301 Redirect (hash fragment 丢失!)
https://ygp.gdzwfw.gov.cn/#/44/index              ← 实际到达首页
```

**修复**：三层面修复

| 层面 | 文件 | 修改 |
|------|------|------|
| 配置层 | `scraper/config.py` | `detail_url_template` 和 `base_url` 改为 `https://` |
| 请求头层 | `scraper/config.py` | `GDGGZY_HEADERS` 的 Origin/Referer 改为 `https://` |
| 数据层 | `scripts/backfill_content.py` | 已修复 37 条现有 GDGGZY 数据的 URL |
| 前端层 | `frontend/index.html` fixUrl() | 新增 `http://ygp` → `https://ygp` 自动转换 |
| CI 层 | `scripts/fix_data_urls.py` | 新增 `fix_gdggzy_url()` 函数，CI 构建时自动修复 |

### 2.3 问题3：正文内容缺失

**根因**：
- GDGPO 爬虫有详情采集功能（调用 `getInfoById` API），但之前采集时因 ConnectTimeout 导致 GDGPO 整体失败，12 条 GDGPO 记录均无 `content` 字段
- GDGGZY 爬虫本身没有详情采集功能（该平台无公开的详情 API）

**修复**：
- 创建 `scripts/backfill_content.py` 回填脚本
- 对 12 条 GDGPO 记录调用详情 API，逐一获取正文内容
- 清洗 HTML → 纯文本 → 截取前 2000 字摘要 → 写入 `content` 字段
- 运行 `scripts/build_index.py` 重建搜索索引（含 content 字段）

**结果**：
```
GDGPO: 12 条, 有正文: 12 (100%) ✅
GDGGZY: 37 条, 无详情 API（正常，前端显示"访问原始网页"引导用户跳转）
```

## 六、后续维护

### 6.1 CI 自动修复

`deploy-pages.yml` 在每次部署时自动运行 `fix_data_urls.py`，确保：
- GDGPO 旧格式 URL 被修正
- GDGGZY HTTP URL 被升级为 HTTPS
- 搜索索引与数据文件保持一致

### 6.2 手动回填

如需重新回填正文内容（如新采集的数据缺少 content）：

```bash
python scripts/backfill_content.py
python scripts/build_index.py
```

### 6.3 GDGGZY 内容限制

GDGGZY（广东省公共资源交易平台）不提供公开的详情 API，因此：
- 无法自动采集正文内容
- 前端显示"正文内容暂未采集"并提供"访问原始网页"链接
- 用户需点击链接跳转到 GDGGZY 网站查看完整内容
