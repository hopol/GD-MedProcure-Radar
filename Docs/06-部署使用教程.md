## 第一章：安装 Git

### 什么是 Git？

Git 是一个"版本管理工具"，你可以把它理解为**代码的同步工具**。它能帮你把电脑上的代码上传到 GitHub（一个在线代码托管平台），也能把 GitHub 上的代码下载到你的电脑。

### 安装步骤（Windows）

1. 打开浏览器，访问 Git 官网：https://git-scm.com/download/win
2. 页面会自动开始下载。如果没有，点击 **"Click here to download manually"**
3. 双击下载的 `.exe` 文件
4. 安装过程中，**所有选项保持默认**，一路点 **"Next"** 直到 **"Install"**
5. 点 **"Finish"** 完成安装

### 验证安装成功

1. 在桌面或文件管理器中，**右键点击空白处**
2. 选择 **"在终端中打开"** 或 **"Git Bash Here"**
3. 在弹出的黑色窗口中输入：
   ```
   git --version
   ```
4. 如果显示类似 `git version 2.43.0.windows.1` 的文字，说明安装成功

### 配置 Git 身份（必须）

在刚才的窗口中，依次执行以下两条命令（把引号里的内容替换成你自己的）：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
```

> 这里的名字和邮箱会显示在你每次提交的代码记录中。建议用和 GitHub 注册时相同的邮箱。

## 第二章：安装 Python

### 什么是 Python？

Python 是一种编程语言。我们项目中的爬虫（自动采集数据的程序）就是用 Python 写的。你需要安装 Python 才能运行它。

### 安装步骤（Windows）

1. 打开浏览器，访问 Python 官网：https://www.python.org/downloads/
2. 点击 **"Download Python 3.x.x"** 黄色按钮下载
3. 双击下载的 `.exe` 文件
4. **最关键的一步：在安装界面底部，勾选 "Add Python to PATH"**（非常重要！不勾选会导致命令行找不到 python）
5. 然后点击 **"Install Now"**
6. 等待安装完成，点 **"Close"**

### 验证安装成功

1. 按 `Win + R`，输入 `cmd`，回车，打开命令提示符
2. 输入：
   ```
   python --version
   ```
3. 如果显示类似 `Python 3.12.1` 的文字，说明安装成功

> **注意：** 如果显示"不是内部或外部命令"，说明安装时没有勾选 "Add Python to PATH"。请重新安装并确保勾选。

## 第三章：注册 GitHub 账号

### 什么是 GitHub？

GitHub 是一个**在线代码托管平台**。你可以把代码存在上面，它还能帮你自动运行定时任务（GitHub Actions）和托管网站（GitHub Pages）。

**完全免费。**

### 注册步骤

1. 打开 https://github.com/signup
2. 输入你的邮箱地址
3. 设置一个密码
4. 设置一个用户名（英文，如 `zhangsan2024`）
5. 按提示完成验证（通常是拼图或邮件验证码）
6. 点击 **"Create account"**
7. 去邮箱点击验证链接

> 用户名很重要，它会出现在你网站的地址中：`https://你的用户名.github.io/GD-MedProcure-Radar/`

## 第四章：在 GitHub 上创建仓库

### 什么是仓库？

"仓库"（Repository）就是 GitHub 上的一个**项目文件夹**。你所有的代码和数据都存在这个文件夹里。

### 创建步骤

1. 登录 GitHub 后，点击右上角的 **"+"** → **"New repository"**
2. 填写信息：

| 选项 | 填写内容 |
|------|---------|
| Repository name | `GD-MedProcure-Radar` |
| Description | `广东省医疗设备采购信息监测系统` |
| Public | 选择 **Public**（公开） |
| Add a README | **勾选** ✅ |

3. 点击 **"Create repository"**

创建成功后，你会看到仓库页面，地址类似：
```
https://github.com/你的用户名/GD-MedProcure-Radar
```

> **记住这个地址，后面会多次用到。**

## 第五章：把代码下载到你电脑上

### 方法一：如果你已经有代码文件夹

如果你是通过其他方式获得了 `GD-MedProcure-Radar` 文件夹（比如别人给你的 U 盘，或者你已经在这个文件夹里了），可以跳过下载步骤，直接进入第六章。

1. 打开命令提示符（`Win + R` → `cmd`）

   ```bash
   cd E:\你的路径\GD-MedProcure-Radar
   ```

3. 执行：
   ```bash
   git init
   git remote add origin https://github.com/你的用户名/GD-MedProcure-Radar.git
   ```

### 方法二：从 GitHub 下载空仓库，再把代码放进去

1. 打开命令提示符
2. 执行以下命令（把 `你的用户名` 替换成你的 GitHub 用户名）：
   ```bash
   cd E:\
   git clone https://github.com/你的用户名/GD-MedProcure-Radar.git
   ```
3. 这会在 `E:\` 下创建一个 `GD-MedProcure-Radar` 文件夹
4. 把你的所有代码文件**复制到这个文件夹里**

## 第六章：安装 Python 依赖库

### 什么是依赖库？

我们的爬虫代码需要用到一些别人写好的工具包（比如用来发送网络请求的 `requests`）。安装依赖库就是把这些工具包下载到你的电脑上。

### 操作步骤

1. 打开命令提示符（`Win + R` → `cmd`）
2. 进入项目文件夹：
   ```bash
   cd E:\GD-MedProcure-Radar
   ```
   （如果你放在了其他位置，请替换成正确的路径）

3. 安装依赖：
   ```bash
   pip install -r scraper/requirements.txt
   ```

4. 等待下载和安装，你会看到很多文字滚动。最终出现 `Successfully installed ...` 就说明成功了。

> **如果报错 "pip 不是内部命令"：** 回到第二章，确保 Python 安装时勾选了 "Add to PATH"，然后重新打开命令提示符。

> **如果下载很慢：** 可以用国内镜像加速：
> ```bash
> pip install -r scraper/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

## 第十一章：创建 Personal Access Token（PAT）

### 为什么需要 PAT？

GitHub 在 2021 年取消了用密码推送代码的方式。你需要创建一个"令牌"（Token）来代替密码。

另外，我们的项目有一个特殊需求：爬虫采集完数据后，需要自动触发"前端部署"工作流。但 GitHub 默认不允许一个工作流触发另一个工作流，除非使用 PAT。

### 创建步骤

1. 打开 https://github.com/settings/tokens?type=beta
   （这是 Fine-grained Token 创建页面，比传统 Token 更安全）

2. 点击 **"Generate new token"**

3. 填写信息：

| 选项 | 填写内容 |
|------|---------|
| Token name | `GD-MedProcure-Radar Actions` |
| Description | `用于 GitHub Actions 自动推送数据并触发部署` |
| Expiration | 选择 **1 year**（一年后需要重新生成） |
| Repository access | 选择 **"Only select repositories"** → 选中 `GD-MedProcure-Radar` |

4. 点击 **"Add permissions"** → 展开 **"Repository permissions"**：

| 权限 | 设置 |
|------|------|
| Actions | **Read and write**（读写工作流） |
| Contents | **Read and write**（读写代码文件） |
| Metadata | **Read-only**（只读，默认就有） |
| Pages | **Read and write**（读写 GitHub Pages） |

5. 点击底部的 **"Generate token"**

6. **立刻复制 Token！** 它只会显示一次，以 `github_pat_` 开头的一长串字符。
   把它保存在一个安全的地方（比如记事本），关闭页面后就再也看不到了。

> **安全提示：** Token 相当于你 GitHub 账号的钥匙，不要告诉任何人，不要发到公开场所。

## 第十二章：配置 GitHub Actions 密钥

把刚才创建的 Token 存到仓库的密钥管理中。

### 步骤

1. 打开你的仓库页面：`https://github.com/你的用户名/GD-MedProcure-Radar`

2. 点击顶部的 **"Settings"**（齿轮图标）

3. 左侧菜单找到 **"Secrets and variables"** → 点击 **"Actions"**

4. 点击 **"New repository secret"**

5. 填写：

| 选项 | 填写内容 |
|------|---------|
| Name | `GH_PAT` |
| Secret | 粘贴你刚才复制的 Token（`github_pat_...` 那一大串） |

6. 点击 **"Add secret"**

> 这个密钥会被 GitHub Actions 自动读取，用于推送数据和触发部署。你的代码里已经配置了自动使用这个密钥的逻辑。

## 第十四章：手动触发第一次数据采集

现在代码已推送、密钥已配置、Pages 已开启。我们来手动运行第一次完整的自动化流程。

### 步骤

1. 打开仓库页面，点击顶部的 **"Actions"**

2. 左侧可以看到两个工作流：
   - **"数据采集与更新"**
   - **"构建并部署到 GitHub Pages"**

3. 点击 **"数据采集与更新"**

4. 右侧出现 **"Run workflow"** 按钮，点击它

5. 弹出的表单中：

| 选项 | 建议值 | 说明 |
|------|--------|------|
| Branch | `main` | 默认即可 |
| 采集近 N 天的数据 | `7` | 默认采集最近 7 天 |
| 指定数据源 | 留空 | 留空表示采集全部数据源 |
| 跳过前端部署触发 | 不勾选 | 我们需要部署网站 |

6. 点击绿色的 **"Run workflow"**

7. 你会看到一个黄色的运行状态条，等待它运行。大约 2~5 分钟后：
   - 运行状态变为 ✅ 绿色 = 成功
   - 它会自动触发 **"构建并部署到 GitHub Pages"** 工作流

8. 点击左侧的 **"构建并部署到 GitHub Pages"**，查看部署进度
   - 部署完成后同样显示 ✅ 绿色

## 日常使用指南

### 自动模式（推荐）

部署完成后，你**什么都不用做**。系统会自动运行：

- **每天北京时间 08:00**：自动采集前一天到前 7 天的数据
- **每天北京时间 14:00**：再次采集更新
- 采集完成后**自动更新网站**

你只需要打开网站地址就能看到最新数据。

### 手动触发采集

如果你想立即更新数据（不想等到下一个定时时间）：

1. 打开仓库 → **Actions** → **"数据采集与更新"**
2. 点击 **"Run workflow"**
3. 设置参数 → **"Run workflow"**
4. 等待 2~5 分钟，网站自动更新

### 查看运行日志

如果想知道采集是否成功、有没有报错：

1. 打开仓库 → **Actions**
2. 点击某次运行的标题（如 "Run workflow #15"）
3. 展开各个 Step，可以看到详细的运行日志

### 修改采集频率

默认每天 08:00 和 14:00 各运行一次。如果你想修改：

1. 在仓库中找到文件：`.github/workflows/update-data.yml`
2. 找到 `schedule` 部分：
   ```yaml
   schedule:
     - cron: '0 0 * * *'    # 北京时间 08:00
     - cron: '0 6 * * *'    # 北京时间 14:00
   ```
3. 修改 Cron 表达式（注意：GitHub 使用 UTC 时间，北京时间 = UTC + 8）：
   - 北京时间 09:00 = UTC 01:00 → `cron: '0 1 * * *'`
   - 北京时间 18:00 = UTC 10:00 → `cron: '0 10 * * *'`
4. 保存并提交

## 常见问题排查（FAQ）

### Q1：爬虫运行时报错 "ConnectionError" 或超时

**原因：** 目标网站临时不可用或你的网络不稳定。

**解决：** 等几分钟重试。如果是 GitHub Actions 上运行失败，等下次定时自动重试即可。

---

### Q2：网站打开后空白，或者显示"正在加载数据"一直不动

**原因：** 数据文件没有正确部署。

**解决：**
1. 检查 **Actions** 中两个工作流是否都是 ✅ 绿色
2. 点击"构建并部署到 GitHub Pages"那次的日志，看有没有报错
3. 确认 `frontend/public/data/` 下有 `procurements.json`、`aggregations.json`、`search-index.json` 三个文件

---

### Q3：搜索框输入中文没有结果

**原因：** 可能是浏览器缓存了旧版本。

**解决：** 按 `Ctrl + Shift + R`（强制刷新）清除缓存重新加载。

---

### Q4：GitHub Actions 运行报错 "permission denied"

**原因：** `GH_PAT` 密钥没有正确配置，或者 Token 已过期。

**解决：**
1. 检查 **Settings** → **Secrets and variables** → **Actions** 中是否有 `GH_PAT`
2. 如果有，确认 Token 没有过期（创建时选的期限）
3. 如果过期了，重新创建 Token（第十一章），更新密钥值

---

### Q5：网站地址打不开（404 错误）

**原因：** GitHub Pages 还没有部署成功，或者你访问的地址不对。

**解决：**
1. 确认 **Settings** → **Pages** 显示的是绿色 ✅ 状态
2. 确认地址格式：`https://你的用户名.github.io/GD-MedProcure-Radar/`
3. 注意用户名是**小写**的，仓库名是**大小写敏感**的

---

### Q6：采集到的数据量为 0

**原因：** 目标网站可能改版了 API，或者搜索关键词没有匹配结果。

**解决：**
1. 查看 Actions 运行日志中的爬虫输出
2. 如果某个数据源返回 0 条，可以手动打开目标网站看看是否有数据
3. 如需修改爬虫代码，参考 `scraper/gd_scraper.py` 和 `scraper/config.py`

---

### Q7：如何添加新的数据源？

需要修改以下文件：
1. `scraper/config.py` — 添加新数据源的 API 地址和配置
2. `scraper/gd_scraper.py` — 编写新的爬虫类
3. `scraper/main.py` — 在调度中调用新爬虫

---

### Q8：如何修改网站界面？

所有前端代码都在 `frontend/index.html` 一个文件中。修改后：
1. 本地测试（第九章的方法）
2. 推送代码到 GitHub（`git add . → git commit → git push`）
3. 手动触发 "构建并部署到 GitHub Pages" 工作流

---

### Q9：Token 一年后过期了怎么办？

1. 按第十一章重新创建一个新的 Token
2. 到 **Settings** → **Secrets** → **Actions** 中，找到 `GH_PAT`，点击编辑图标 🖊️
3. 粘贴新 Token，保存

---

### Q10：如何删除某条错误数据？

1. 在仓库中找到 `data/procurements.json`
2. 点击编辑（铅笔图标），找到那条记录，删除
3. 点击 **"Commit changes"** 提交
4. 系统会自动重新构建索引和部署网站
