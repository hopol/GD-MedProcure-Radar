## 1. 概述

`scripts/build_index.py` 是数据采集后的后处理脚本，负责：

1. 读取 `data/procurements.json`（爬虫产出）
2. 生成 `data/aggregations.json`（聚合统计，供前端筛选面板渲染）
3. 生成 `frontend/public/search-index.json`（FlexSearch 兼容的文档数组）
4. 将数据和聚合文件复制到 `frontend/public/data/`（Vite 构建时直接打包）

---

## 2. 产出文件清单

| 文件 | 用途 | 大小 (49条数据时) |
|------|------|:---:|
| `data/aggregations.json` | 地区/类目/预算等聚合统计 | 3.4 KB |

### 4.1 字段分类

| 类型 | 字段 | FlexSearch 配置 |
|------|------|----------------|
| **搜索字段** (全文索引) | `project_name`, `project_no`, `hospital`, `agency`, `category`, `raw_category` | `index: [...]` |
| **筛选字段** (精确过滤) | `region`, `budget`, `publish_date`, `source`, `notice_type` | 不索引，用于 filter |
| **关联字段** | `id` | `document.id` |

### 4.2 前端 FlexSearch 集成示例

```javascript
import FlexSearch from 'flexsearch';

// 加载索引数据
const docs = await fetch('/search-index.json').then(r => r.json());

// 创建文档索引
const index = new FlexSearch.Document({
  document: {
    id: 'id',
    index: [
      'project_name',
      'project_no',
      'hospital',
      'agency',
      'category',
      'raw_category',
    ],
  },
  tokenize: 'forward',  // 中文前向分词
  cache: 100,
});

// 添加文档
docs.forEach(doc => index.add(doc));

// 搜索
const results = index.search('CT设备', {
  limit: 20,
  enrich: true,  // 返回完整文档
});
```

### 4.3 索引体积优化

索引使用**压缩 JSON 格式**（`separators=(",", ":")`），无缩进和空格。

| 数据量 | 预估索引大小 | 加载时间 (4G) |
|--------|:---:|:---:|
| 100 条 | ~43 KB | <50ms |
| 1,000 条 | ~430 KB | <200ms |
| 10,000 条 | ~4.3 MB | <1s |

```

Step 7: 触发 deploy-pages
```

### 5.2 deploy-pages.yml 更新

构建步骤增加了聚合统计和搜索索引的复制逻辑：
- 复制 `data/aggregations.json` → `frontend/public/data/`
- 检查 `frontend/public/search-index.json` 是否已就绪
- 如索引不存在，尝试运行 `build_index.py` 作为兜底
